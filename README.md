# 📱 Mobile Development Learning Repository  

## 🇺🇸 English

Mobile development learning repository using **Kotlin**, **React Native**, and **C**.  
This project explores cross‑platform mobile development with:  
- ⚡ **Kotlin** → for native Android apps  
- 🌐 **React Native** → for hybrid cross‑platform apps  
- ⚙️ **C** → for native modules and performance‑critical components  

It serves as a practice space for experimenting with different mobile languages and frameworks.

---

### 🎯 Purpose
Most of the code in this repository comes from training exercises, including the **Alura #7DaysOfCode** challenge.  
The goal is to strengthen mobile development skills through hands‑on practice, exploring different paradigms and technologies.

---

### 👨‍💻 About Me
I’m a **Full Stack & Mobile Developer** passionate about building applications across multiple platforms.  
My stack includes:  
- 🖥️ **Backend & Full Stack**: PHP, Kotlin, Node.js, MongoDB  
- 📱 **Mobile**: Kotlin, React Native, C  
- 🌐 **Frontend**: HTML, CSS, JavaScript, React  

This repository reflects my journey of continuous learning and experimentation in mobile development.
